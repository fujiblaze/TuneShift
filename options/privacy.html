TuneShift privacy policy

Effective September 23, 2026.

What TuneShift accesses

When you invoke TuneShift on a tab, it reads that page's URL, title, media elements, media URL or media-session metadata, and playback state to control playback and identify saved settings or BPM. On open.spotify.com, a bundled compatibility hook runs when the page loads. It attaches detached audio elements to the page so TuneShift can control them if you open the extension. The hook wraps media creation and play methods; it does not transmit page data.

What TuneShift saves

TuneShift stores preferences, built-in presets, and up to 20 custom Quick profiles in Chrome's local extension storage. When Remember each page is on, it stores exact-page profiles containing page URLs, titles and control settings, and BPM records identified by page or media URL or media metadata. If you select This track, it also stores tuning for that track using its page and media identity. Turning Remember off stops saving and restoring page and track profiles and BPM records. Existing records remain until you delete them. The history screen can delete one page and its track profiles and BPM records or clear all saved pages, track profiles and BPM records. Custom Quick profiles can be deleted from the Quick profiles section. Uninstalling TuneShift removes its local extension storage.

Page and track profiles are each capped at 200 entries. BPM records are capped at 300 entries and expire 90 days after their last update. Older and excess records are removed during storage maintenance.

Audio processing

Normal effects process media locally in the page. If you choose Enable tab effects, Chrome asks for tab-capture permission. TuneShift processes audio from the selected tab in memory and plays it back locally. It does not record or upload audio.

Sharing and limited use

TuneShift has no account, analytics, advertising, or developer-operated upload service. It does not sell or share user data. TuneShift uses data obtained through Chrome permissions only to provide and maintain its media-control features. It does not use browsing or media data for advertising, and the developer does not access that data. TuneShift complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
